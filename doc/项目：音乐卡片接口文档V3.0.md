# 项目：音乐卡片_接口文档

Druid控制台url：http://localhost:8080/druid/

## 统一返回体

所有接口统一返回：

```json
{
    "status": {
        "code": [Int],
        "msg": [String]
    },
    "result": [Object]
}
```

- status.code：业务状态码，1001 表示成功
- status.msg：状态码说明
- result：业务数据，失败时为 null

### 错误码表

| 1002 | 没有登录哦~ | 未登录 |

### 1、音乐列表

/music/list

参数：

keyword:[String],(required = false)

wp:[String],(required = false)

请求规则：

1. 首次请求不传 `wp`，后端固定查询第 1 页；可以传 `keyword` 搜索，也可以不传 `keyword` 查询全部音乐。
2. 第二页及后续请求只传上一页响应返回的 `wp`，不得同时传 `keyword`，也不再传 `page`。
3. 搜索条件发生变化时，前端必须丢弃旧 `wp`，使用新的 `keyword` 重新发起首次请求。
4. 前端应将 `wp` 视为不透明字符串，不解析、不修改，只负责原样回传。
5. `wp` 无法解码、内容非法，或与 `keyword` 同时传递时，返回业务状态码 `4009`。
6. 后续请求根据上一批结果继续拉取，前端不得自行构造分页位置；分页位置由后端封装在 wp 中。

返回：

```json
{
    "status": {
        "code": [Int],
        "msg": [String]
    },
    "result": {
        list:[
            {
                id:[Long],
                wallImage:{
                    url:[String],
                    ar:[Float]
                },
                musicName:[String],
                singerName:[String],
                musicDesc:[String],
                typeName:[String]
            }
        ],
        isEnd:[Boolean],
        wp:[String]
    }
}
```

## 数据库表设计

```mysql
CREATE TABLE `music` (
  `id` bigint(20) unsigned NOT NULL AUTO_INCREMENT,
  `cover_images` varchar(2000) CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci NOT NULL COMMENT '封面图，$拼接',
  `music_name` varchar(50) CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci NOT NULL COMMENT '歌曲名',
  `singer_name` varchar(50) CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci NOT NULL COMMENT '歌手名',
  `music_desc` varchar(200) CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci DEFAULT NULL COMMENT '歌曲介绍',
  `album_title` varchar(50) CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci DEFAULT NULL COMMENT '专辑名称',
  `release_date` varchar(50) CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci DEFAULT NULL COMMENT '发布日期',
  `create_time` int(10) unsigned NOT NULL,
  `update_time` int(10) unsigned NOT NULL,
  `is_deleted` tinyint(1) unsigned NOT NULL DEFAULT '0',
  `type_id` bigint(20) unsigned DEFAULT NULL COMMENT '音乐类型',
  PRIMARY KEY (`id`),
  KEY `idx_music_name` (`music_name`),
  KEY `idx_singer_name` (`singer_name`),
  KEY `idx_type_id` (`type_id`)
) ENGINE=InnoDB AUTO_INCREMENT=1 DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='音乐表'
```
